# mise

*Mise en place*: everything in its place before you start cooking.

My personal coding conventions:

- `configs/`: Prettier, ESLint and TypeScript config packages that enforce the checkable rules.
- `plugins/`: Claude Code plugins, one per concern, that capture principles and patterns.

## Use in a project

```bash
claude plugin marketplace add RamonGebben/mise
claude plugin install testing@mise
```
